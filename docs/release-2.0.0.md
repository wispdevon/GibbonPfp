# HeadshotFlow 2.0.0

HeadshotFlow 2.0.0 makes it easier to frame, review, and export a batch of
portraits. **Load sample** adds three bundled portraits so you can try the
whole workflow before importing your own photos.

- **Preview / Crop** shows the oriented source and an editable crop outline.
  **Result** shows the processed output. The inspector groups controls into
  **Frame** and **Refine** tabs.
- Drag the workspace dividers to resize the photo queue, both image panels,
  and the inspector. You can also focus a divider with **Tab** and resize
  with the arrow keys.
- Use **Export as…** to choose the photos, output settings, and destination.
  **Quick Export** repeats the last successful export using the current
  photos in its remembered scope.
- Workspace, queue, and photo menus fit on screen at the minimum window
  size and maximum interface scale.

See the [quickstart](quickstart.md) for the sample walkthrough and
[build and distribution instructions](BUILDING.md) for platform-specific
details.
